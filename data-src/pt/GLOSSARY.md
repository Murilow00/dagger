# Glossário e regras de tradução (Daggerheart SRD → português do Brasil)

Contexto: RPG de mesa Daggerheart. Traduza para pt-BR natural, claro e fiel, no tom de um livro de regras (segunda pessoa "você"). A interface do sistema já usa estes termos — seja consistente:

## Termos de regra
Hope = Esperança · Fear = Medo · Stress = Fadiga (Stress slot = espaço de Fadiga; "mark a Stress" = "marque 1 Fadiga"; "clear a Stress" = "limpe 1 Fadiga") · Hit Point (HP) = Ponto de Vida (PV) · Evasion = Evasão · Armor Slot = espaço de Armadura · Armor Score = Valor de Armadura · Damage Thresholds = Limiares de Dano · Major = Maior · Severe = Grave · Minor = Menor · Proficiency = Proficiência · Experience = Experiência · Trait = Atributo · Duality Dice = Dados de Dualidade · Action Roll = Teste de Ação · Reaction Roll = Teste de Reação · Spellcast Roll = Teste de Conjuração · "X Roll" (ex.: Agility Roll) = Teste de X (Teste de Agilidade) · advantage / disadvantage = vantagem / desvantagem · Difficulty = Dificuldade · Tier = Patamar · short rest / long rest = descanso curto / descanso longo · downtime = tempo livre · Loadout = Loadout · Vault = Reserva · Recall (Cost) = Recordar · Domain Card = carta de domínio · Ancestry = Ancestralidade · Community = Comunidade · Subclass = Subclasse · Foundation / Specialization / Mastery = Fundamental / Especialização / Maestria · spotlight = holofote ("to spotlight" = dar o holofote) · GM = Mestre · PC = PJ · NPC = PdM · Adversary = Adversário · Environment = Ambiente · Beastform = Forma de Fera · Companion = Companheiro · Minion = Lacaio · Horde = Horda · Solo = Solo · Bruiser = Brutamontes · Leader = Líder · Ranged = À distância · Skulk = Espreitador · Support = Suporte · Standard = Padrão · Gold = ouro (handful/bag/chest = punhado/bolsa/baú) · Hope Feature = Habilidade de Esperança · Class Feature = Habilidade de Classe · attack roll = teste de ataque · damage roll = teste de dano · "Help an Ally" = Prestar Ajuda · "Utilize an Experience" = Usar uma Experiência.
Alcances: Melee = Corpo a corpo · Very Close = Muito Próximo · Close = Próximo · Far = Distante · Very Far = Muito Distante.
Condições: Vulnerable = Vulnerável · Hidden = Escondido · Restrained = Imobilizado · Cloaked = Oculto · Poisoned = Envenenado · Distracted = Distraído · Asleep = Adormecido · Stunned = Atordoado (use bom senso nas demais).
Dano: "phy"/"physical" = "fís"/"físico"; "mag"/"magic" = "mág"/"mágico" (ex.: "d8+2 phy" → "d8+2 fís"; "magic damage" → "dano mágico").
Classes (não traduza o nome em inglês quando for identificador de dados, mas no texto use): Bard = Bardo, Druid = Druida, Guardian = Guardião, Ranger = Patrulheiro, Rogue = Ladino, Seraph = Serafim, Sorcerer = Feiticeiro, Warrior = Guerreiro, Wizard = Mago.
Domínios: Arcana = Arcano, Blade = Lâmina, Bone = Falange, Codex = Códice, Grace = Graça, Midnight = Meia-noite, Sage = Sabedoria, Splendor = Esplendor, Valor = Valor.
Atributos: Agility = Agilidade, Strength = Força, Finesse = Acuidade, Instinct = Instinto, Presence = Presença, Knowledge = Conhecimento.
Ancestralidades: Clank = Clank, Drakona = Drakona, Dwarf = Anão, Elf = Elfo, Faerie = Fada, Faun = Fauno, Firbolg = Firbolg, Fungril = Fungril, Galapa = Galapa, Giant = Gigante, Goblin = Goblin, Halfling = Halfling, Human = Humano, Inferis = Inferis, Katari = Katari, Orc = Orc, Ribbit = Ribbit, Simiah = Simiah.
Comunidades (usadas como adjetivo de "comunidade"): Highborne = Aristocrática, Loreborne = Erudita, Orderborne = Ordeira, Ridgeborne = Montanhesa, Seaborne = Marítima, Slyborne = Dissimulada, Underborne = Subterrânea, Wanderborne = Nômade, Wildborne = Selvagem. Em frases como "Wildborne are often hardy…" escreva "Quem pertence a uma comunidade selvagem costuma ser…".

## Regras de formato (obrigatórias)
- Preserve EXATAMENTE a marcação: `**negrito**`, `_itálico_`, quebras de linha (`\n`), listas (`- item`), títulos (`### ...`). Mesmo número de cada.
- Preserve todos os números, dados e bônus como estão (d12, 2d6+3, +2, -1, 1d4…). Não troque algarismos por palavras nem o contrário.
- Itens entre `_..._` e termos de jogo em negrito devem ser traduzidos mas mantendo a marcação em volta.
- Nomes próprios de personagens/lugares do cenário (ex.: Ava, Tava, Illiat, Fortunis) permanecem. Nomes de itens, cartas, armas e criaturas: traduza de forma natural e curta (a lista de nomes já traduzidos está em data-src/pt/translations.json: se um nome aparecer no texto, use a tradução de lá).
- Não explique, não comente, não omita nada. Uma tradução por chave.
